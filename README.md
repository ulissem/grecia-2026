# Grecia 2026 — guida di viaggio (PWA)

Guida personale per il viaggio Itea → Peloponneso → Atene, 12–17 ottobre 2026.

## Pubblicare (una volta sola)
1. Carica **tutti** i file di questa cartella nella radice del repository `grecia-2026` (Add file → Upload files → Commit).
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main`, cartella `/ (root)` → Save.
3. Dopo 1–2 minuti la guida è online su **https://ulissem.github.io/grecia-2026/**

## Installare come app
- **iPhone**: apri l'indirizzo in Safari → Condividi → *Aggiungi alla schermata Home*.
- **Android**: apri in Chrome → menu ⋮ → *Installa app* (o *Aggiungi a schermata Home*).

Dopo la prima apertura la guida funziona anche offline; meteo e foto si aggiornano quando c'è rete.

## Aggiornare la guida
Sostituisci `index.html` nel repository (Upload files, stesso nome). Nel file `sw.js` cambia `grecia-2026-v1` in `v2`, `v3`… così le app installate scaricano la versione nuova alla prossima apertura.
